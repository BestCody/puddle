# Valantir

A responsive recreation of the Valantir public website and account-entry experience.

## Included

- Full landing page with product preview, mission, founders, organization workflow, testimonials, FAQ, and footer
- Responsive mobile navigation and layouts
- Student and organization sign-in/sign-up flows
- Help, terms, and privacy pages
- Interactive newsletter, FAQ, and form states
- Vercel SPA routing configuration

## Development

```bash
npm run dev
```

## Validation and production build

```bash
npm run check
npm run build
```

The public interface is complete. Authentication, database, email verification, messaging, and hour tracking require backend services to be connected separately.
